# 小程序对接验收

- [ ] `wx.login` 能换取 Token，未绑定 openid 显示明确错误。
- [ ] 单设备重新登录后，旧 Token 返回 401。
- [ ] 司机只能看到本人任务，店长只能看到本站点任务。
- [ ] PUBLISHED 任务可接单；越级开始运输返回 409。
- [ ] 取货和送达使用真实二维码原文；错误或过期二维码返回明确错误。
- [ ] 多站任务按 stop 顺序送达，每次使用返回的新版本。
- [ ] 旧版本写入返回 `409 VERSION_CONFLICT`，页面刷新后再决定。
- [ ] 相同幂等键和正文重试只产生一条扫码、轨迹、签收或日报记录。
- [ ] 相同幂等键与不同正文返回 `409 IDEMPOTENCY_CONFLICT`。
- [ ] GPS 断网时进入 outbox，恢复后保留原 `recorded_at` 上传。
- [ ] 超温、超湿产生报警，司机和网页在 5 秒目标内可见。
- [ ] 全量签收必须等于任务明细；差异签收必须存在差异；拒收实收为零。
- [ ] 签收成功后库存只增加一次，不再执行第二次扫码入库。
- [ ] 第三空间首页突出签收、缺货、经营日报三个入口。
- [ ] 第三空间缺货和授权日报能在网页投影中出现。
- [ ] WSS 按 cursor 重连，不丢事件；不可用时 REST 轮询 30 秒降级。
- [ ] 非图片、伪造图片头、超过 10 MB 和越权下载均被拒绝。
- [ ] 生产包没有默认 Mock、固定未来日期、云数据库业务双写。
- [ ] 所有展示状态和错误为中文，内部枚举保持英文稳定值。
- [ ] 真机 HTTPS/WSS、上传、位置和隐私授权全部通过。
